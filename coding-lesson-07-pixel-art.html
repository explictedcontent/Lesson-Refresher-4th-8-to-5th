🖌️ Make It Paintable
Now the magic: when you TAP a cell, it fills with your color. That's an EVENT — code that runs when you do something. Pick a color, then paint at least 10 cells. Drag to paint fast!
cell.onclick = function() { // when this cell is tapped... cell.color = currentColor; // paint it! };

Tapping a cell fires an event, and the event runs code that changes that cell's color. Every button, every tap, every click in every app works this way: an event happens → code responds.

Build Step 4 of 4
🧰 Add Your Tools
Real apps have tools. Each tool is a FUNCTION (Level 2!). You get an ERASER, a CLEAR-ALL button, and a FILL button that paints the whole canvas one color. Try each one!
function clearCanvas() { for (let cell of grid) { // loop every cell... cell.color = 'blank'; // ...and reset it } }
Each tool is a function that loops over the grid: the eraser paints "blank," fill paints one color everywhere, clear resets it all. One button → one function → the whole grid changes. That's how tools work.
