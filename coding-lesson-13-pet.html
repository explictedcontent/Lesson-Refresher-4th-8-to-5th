Build Step 3 of 4
🍜 Add Care Actions
Each action is a FUNCTION (Level 2!) that changes the pet's stats. Try Feed, Play, and Sleep — watch the bars move. Use all three to continue!
function feed() { pet.fullness = pet.fullness + 30; if (pet.fullness > 100) pet.fullness = 100; // never over 100 }
Each button calls a function that changes a stat. Notice the if that stops a stat going over 100 — that's called "clamping." Feeding fills the belly; playing costs energy. Actions change the pet's state.

Build Step 4 of 4
⏳ Time Makes It Change
Here's the magic: a TIMER (Level 8!) slowly lowers the stats over time — your pet gets hungry and tired all by itself! Press START and watch. Care for it if a bar gets low.
setInterval(function() { pet.fullness = pet.fullness - 4; // gets hungry over time pet.energy = pet.energy - 3; updateFace(); // mood changes if a stat is low }, 1500);
A timer keeps changing the pet's stats even when you do nothing — that's called STATE changing over time. An if checks the numbers and picks the pet's mood face. Now it feels alive!
⏳
Your pet is alive — it changes on its own!
