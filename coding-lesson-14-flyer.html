Build Step 1 of 4
⬇️ Code Gravity
Gravity doesn't pull at a steady speed — it makes things fall FASTER and faster. In code: add a little to the speed each frame, then move by that speed. Press DROP and watch!
speed: 0
let speed = 0; function everyFrame() { speed = speed + gravity; // gravity builds up speed y = y + speed; // move down by the speed }
Gravity adds to the speed every frame, and the speed moves the position. So the ball falls slowly at first, then faster and faster — just like real gravity! Two lines of code make real physics.
Build Step 2 of 4
🪶 Add the Flap
Gravity keeps pulling you down — so how do you go up? Tapping sets your speed to a strong UP push. Tap the game (or the FLY button) to stay in the air. Flap 6 times to continue!
onTap(() => { speed = -8; // a negative speed means UP! });
A tap sets your speed to a negative number — and negative means UP on the screen. Then gravity slows you and pulls you back down, so you keep tapping to stay aloft. That's the whole feel of a flying game!
Build Step 3 of 4
☁️ Add Obstacles
Now for a challenge! Clouds scroll toward you with a gap to fly through. If you touch a cloud, you crash — that's collision detection. Fly through 2 gaps to continue!
☁️ Passed: 0 / 2
if (bird hits a cloud) { crash(); // collision! start over }
The game checks every frame: is the bird touching a cloud? That's collision detection (Level 10!). Fly through the GAP and you're safe; touch a cloud and you crash. Physics + collision = a real game.
☁️
You dodged the clouds!
Build Step 4 of 4
⭐ Add the Score
A game needs a goal! Each time you pass a cloud, an if-statement adds 1 to your score. Score 3 points to continue.
⭐ Score: 0 / 3
if (bird passed a cloud) { score = score + 1; // a point for each dodge! }
When a cloud slides past you safely, an if-statement adds 1 to the score. Physics moves you, collision can end the run, and scoring rewards you — all the pieces of a game working together.

Scoring works — it's a real game!
