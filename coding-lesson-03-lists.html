Mission 3 of 5
🔁 Eat the WHOLE Stash
Grabbing one at a time is slow. A LOOP visits every item in the list automatically — first to last — no matter how long it is. Hit RUN and watch.
The code:
for (let item of stash) { panda.eat(item); // runs once for EVERY item }
0

The loop ran once per item — automatically. If the stash had 1,000 items, the SAME 3 lines would eat all 1,000. Loops + lists are how programs handle playlists, photo galleries, and game inventories.
