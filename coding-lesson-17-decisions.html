🤔 Panda Decides
Until now your code did the same thing every time. Now it will look around and decide. That's the idea behind every game, app, and robot — code that checks something, then chooses what to do.
🧠 Start here — the new idea
There's a new command: blocked(). It doesn't move the panda — it asks a question:

“Is there a wall 🧱 right next to me, on my right?”

The answer comes back as true (yes) or false (no). Those two words are how code says yes and no. 
blocked()  →  true    (yes, a wall is there)
blocked()  →  false   (no, the way is clear)
In the missions you'll use that answer to decide what the panda does next.

Your commands:

right()left()up()down()blocked()say(...)

The panda grabs any 💎 gem it steps on. Clear every gem to win.
