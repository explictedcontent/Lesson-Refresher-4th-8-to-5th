# ☀️ Summer Refresher Course · 4th → 5th Grade

A self-paced summer course to keep skills sharp for next school year — a mix of
subjects from 4th grade plus a head start on 5th. Every lesson is a single
interactive HTML page: tap to answer, earn XP, and a grown-up answer key unlocks
at the end.

**👉 Open `index.html` for the front page** — all subjects listed, click any lesson to start.

## How to use it
- **Easiest:** open `index.html` and tap a lesson. Progress saves automatically on the device.
- Each math lesson takes ~30 minutes, with a warm-up review, teaching, practice, a boss round, and stretch riddles.
- Wrong answers lock and stay marked so a grown-up can review them; the **Answer Key** at the bottom of each lesson unlocks once every problem is answered.

> Tip: to make every link clickable on any phone or tablet, turn on **GitHub Pages**
> for this repo (Settings → Pages → Branch: `claude/new-session-g52atj`, folder `/root`).
> That publishes the front page at a web address you can bookmark.
