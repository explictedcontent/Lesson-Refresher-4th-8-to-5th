🕹️ Move by Coordinates

🧱 Walls Block the Way
Now there are WALLS. Before the panda moves, the code checks: is the next spot a wall? If yes, it can't move there. Wind your way around to the flag!

if (grid[nextRow][nextCol] === WALL) { // blocked! don't move. } else { panda.row = nextRow; panda.col = nextCol; }
That check is collision detection: before moving, the code asks "is that spot a wall?" If yes, the move is blocked. Walls, edges, enemies — games check the next spot before every step.

Build Step 4 of 4
🏁 The Win Check
How does a game know you WON? It checks: is the panda's spot the SAME as the goal's spot? First TAP any open cell to place the flag, then drive the panda to it!
👆 Tap an open square to place the flag
if (panda.row === goal.row && panda.col === goal.col) { youWin(); // same spot = you reached the goal! }
The win check compares two coordinates: is the panda's (row, col) the same as the goal's? When they match, you win. Coins, exits, checkpoints — all just "are these two spots the same?"
