Sometimes you want to control HOW a function runs. An INPUT (called a parameter) lets you dial in the details.

function eatBamboo(count) { // panda eats 'count' stalks for (let i = 0; i < 3; i++) { eatOneStal(); } } eatBamboo(3); // call it with input!
The value inside the parentheses eatBamboo(3) is the INPUT. Functions can have 0, 1, 2, or more inputs — each one controls how the function behaves. Same function, different inputs → different results!
