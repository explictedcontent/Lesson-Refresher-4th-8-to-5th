Roblox Studio · Part 2
⚡ Make It Do Something
Last time you built things. Now you'll make them react. A block that just sits there isn't a game — a block that does something when a player touches it is. That one idea powers coins, traps, checkpoints and doors in almost every Roblox game.
🧠 Start here — the two new ideas
1. A list holds many things in one variable. You make one with curly braces, and you grab an item by its position number in square brackets. 
local colors = {"Bright red", "Bright blue"}
print(colors[1])   --> Bright red
⚠️ Lua counts from 1, not 0. The first item is [1]. (Lots of languages start at 0 — Lua doesn't.)

2. An event lets your code wait for something to happen and then run. Touched fires the moment a player bumps into your part. 
part.Touched:Connect(function(hit)
  part.BrickColor = BrickColor.new("Bright green")
end)
You're saying: “when this is touched, run this code.” Studio calls that connecting to the event.
🎮 Reminder — running this in real Roblox Studio
  1. Open Studio → New → Baseplate (desktop only — Studio doesn't run on a phone).
  2. View → turn on Output and Explorer.
  3. In Explorer, hover Workspace → + → Script.
  4. Paste your code, press ▶ Play, then walk your character into the part to fire the Touched event.

In this window there's no character to walk around — so after you press PLAY, hit the 👆 Touch it button to fire the event, exactly like a player bumping into your part.
