Mission 1 of 5
🎲 Make the Computer Roll
Computers can pick a number NOBODY can predict — not even the programmer. That's what random() does. Roll the dice 5 times and watch: can you guess the next one? (You can't. That's the point!)
let roll = random(1, 6); // pick 1,2,3,4,5 or 6 — surprise me!

Every roll is a surprise — even to the computer's programmer! random(1, 6) means "pick any whole number from 1 to 6." Random numbers power dice games, shuffled playlists, loot drops, and every "critical hit" in every game you've ever played.

Mission 2 of 5
📊 Prove It's Fair
If the dice are REALLY random, every number should come up about the same amount... eventually. Let's roll 100 times in one click (that's a LOOP doing the work) and count what happens.
let counts = [0,0,0,0,0,0]; // a LIST! (Level 3 skills) for (let i = 0; i < 100; i++) { // a LOOP! (Level 1 skills) let roll = random(1, 6); counts[roll - 1] = counts[roll - 1] + 1; }
The tally:
Total rolls: 0
No number "wins" forever — with enough rolls they all land around the same count (~16 each per 100). That's what FAIR randomness looks like. Casinos, game designers, and scientists all check randomness exactly this way: roll a LOT and count.

300 rolls tallied — fairness proven!
Mission 3 of 5
⚔️ Random = Damage
In games, attacks don't always hit the same — that would be boring! Attack power = a random number. Land 3 attacks on the training dummy and watch the damage change every time.
function attack() { let damage = random(5, 20); // 5 to 20 — you never know! return damage; }
The training dummy awaits...
Same button, different damage every time — because random(5, 20) picks a new number per attack. This tiny trick is why games feel alive: same move, always a little different. It's a FUNCTION (Level 2) with RANDOMNESS (Level 4) inside!
⚔️
3 hits — every one different!
Mission 4 of 5
💥 Critical Hits
Here's the magic combo: random + IF. Roll the crit die — if it lands on 6, your damage DOUBLES with a golden CRIT! Get 2 crits to complete the mission. (Each roll has a 1-in-6 chance...)
let damage = random(5, 20); let critRoll = random(1, 6); if (critRoll === 6) { // Level 1 skill: if-statements! damage = damage * 2; // 💥 CRITICAL HIT — double damage! }
🎲
Roll a 6 on the crit die for DOUBLE damage...
Crits landed: 0 / 2
if (critRoll === 6) — one line decides whether the hit is normal or LEGENDARY. Random numbers + if-statements = loot drops, shiny Pokémon, enchantment rolls... basically every exciting surprise in every game ever made.
