🎮 Code Your Own Roblox Game
This is the real thing. Roblox games are coded in a language called Lua, and that's exactly what you'll type here. Build it in this window first, then copy it straight into Roblox Studio on your computer — the code is identical.
🧠 Start here — how Roblox code works
Everything in a Roblox game is an Object. A block is a Part. The 3-D world your parts live in is called workspace.

Two things you'll do constantly:
1️⃣ Make an object — Instance.new("Part")
2️⃣ Change its properties — its color, its size, whether it floats. 
local block = Instance.new("Part")   -- make one
block.Parent = workspace             -- put it in the world
That word local just means "make a variable." And -- starts a comment — a note for humans that Lua ignores.
🎮 Get Roblox Studio ready (do this once)
  1. Open Roblox Studio on a computer (it's free — download it from the Roblox site; it doesn't run on a phone).
  2. Click New → pick the Baseplate template.
  3. Top menu: View → turn on Output and Explorer.
  4. In the Explorer panel, hover over Workspace, click the +, and choose Script.
  5. Delete the print("Hello world!") line it starts with — you'll type your own.
  6. Press ▶ Play to run it, and Stop when you're done.
