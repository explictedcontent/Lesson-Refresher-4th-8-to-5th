💡 Key Idea Variables can change! That's the whole point — "vary-able" means able to vary. When the variable changes, everything using it updates automatically!

🔁 Loops — Do It Again!

A loop repeats the same action many times — without writing it over and over!

🎮 Drag the slider — watch the forest grow LIVE!
3
for (let i = 0; i < 3; i++) { plantBamboo(); // runs 3 time(s)! }
💡 Without a loop: plantBamboo(); plantBamboo(); plantBamboo(); plantBamboo(); ... 😩

💡 With a loop: The computer does all that work with just 3 lines of code! 🎉
