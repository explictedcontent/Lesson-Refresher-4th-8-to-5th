Why say something 10 times when you can say it ONCE and let the computer repeat it? That's a LOOP.
🎮 Drag the slider — forest grows LIVE:
3
for (let i = 0; i < 3; i++) { plantBamboo(); // fires 3 time(s)! 🔥 }
This is a LOOP. Instead of typing plantBamboo() ten times in a row (boring! 😴), one loop does it all. Coders are lazy in a SMART way — they never do something twice when a loop can do it for them.
