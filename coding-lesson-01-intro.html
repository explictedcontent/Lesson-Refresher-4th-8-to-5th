Part 1 — What Is Coding? (8 min)

Computers only do exactly what you tell them

Coding (also called programming) means writing instructions for a computer to follow. Computers are incredibly fast — but also incredibly literal. They do exactly what you say, nothing more.

Imagine giving directions to a robot friend who has never been to your house:

  • Walk forward 10 steps
  • Turn right
  • Open the door
  • Say "Hello!"

Those are instructions — just like code! Code is written in special languages computers understand, like JavaScript, Python, Scratch, or Java.

In this lesson, you'll learn the most important building blocks of coding. By the end, you'll write real code that actually runs right here in your browser!

3 things every program needs

Part 2 — Variables: Boxes That Store Things (12 min)

Concept
A variable is like a labeled box 📦

A variable stores a piece of information — a number, a word, anything. You give it a name so you can use it later. In JavaScript we write:

let age = 10; let name = "Alex"; let score = 0;

let = "create a box"  ·  = means "put this inside"  ·  ; ends the instruction

Words (called strings) go in quotes. Numbers don't need quotes.

Concept
Changing what's in the box
let score = 0; score = score + 10; // score is now 10 score = score + 5; // score is now 15

Lines starting with // are comments — notes for humans. The computer ignores them.

Part 3 — If Statements: Making Decisions (12 min)

Concept
if / else = the computer makes a choice

An if statement says: "IF this is true, do this. Otherwise (else), do that."

let score = 85; if (score >= 90) { console.log("A! Amazing job!"); } else if (score >= 70) { console.log("B! Good work!"); } else { console.log("Keep practicing!"); }

The computer checks the conditions top to bottom. First true one wins!

Comparison operators: >= (greater or equal)  ·  <= (less or equal)  ·  === (exactly equal)  ·  !== (not equal)

Part 4 — Loops: Doing Things Over and Over (10 min)

Concept
A loop repeats code so you don't have to

What if you wanted to say "Hello!" 100 times? You don't want to write the same line 100 times! A for loop does it for you:

for (let i = 1; i <= 5; i = i + 1) { console.log("Hello number " + i); } // Prints: Hello number 1, 2, 3, 4, 5

Breaking it down:

  • let i = 1 — start counting at 1
  • i <= 5 — keep going while i is 5 or less
  • i = i + 1 — after each loop, add 1 to i
