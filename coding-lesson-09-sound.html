Build Step 1 of 4
🔊 Make a Sound
Sound is a wave that wiggles the air. The computer makes a note by choosing a FREQUENCY — how fast the wave wiggles. Higher number = higher pitch. Tap all three to hear it!
playTone(440); // 440 = the pitch (frequency in Hz)
A bigger frequency number makes a higher-pitched sound. 220, 440, 880 — each doubling jumps up an octave! The computer builds every note from a number. That's all a "note" really is.
Build Step 2 of 4
🎵 A List of Notes
Music uses a set of notes. Yours is a LIST of frequencies (Level 3!). These 5 notes always sound good together. Tap them to play a little tune — hit at least 5 taps!
let notes = [262, 294, 330, 392, 440]; // C D E G A — tap one to play notes[i]
Your notes live in a list. Tapping the 3rd pad plays notes[2]. A melody is really just a list of notes played in an order — and code is great at lists!
Build Step 3 of 4
🎹 Build the Note Grid
A beat maker is a GRID: each row is a note, each column is a beat in time. Tap squares to place notes (you'll hear each one). Place at least 5 notes to continue!
Notes placed: 0 / 5
// pattern[row][col] = true means "play this note on this beat" pattern[2][0] = true; // note E on beat 1
The grid is a 2D pattern — rows of notes across columns of time. Each lit square says "play THIS note on THIS beat." You're writing music as data!
🎹
Notes placed — now let's play them!
Build Step 4 of 4
🥁 Play the Beat
Here's the magic: a TIMER (Level 8!) moves a playhead across the columns. On each beat, it checks that column and plays every lit note. Press PLAY and listen to your pattern loop!
setInterval(function() { for (let row = 0; row < 5; row++) { if (pattern[row][step]) playTone(notes[row]); } step = (step + 1) % 8; // next beat, then loop }, beatTime);
One timer walks the playhead across the beats; a loop checks the whole column and plays every lit note at once. Timer + loop + list = a working music sequencer. That's real code powering real sound!

Your pattern is playing — it's a real beat maker!
