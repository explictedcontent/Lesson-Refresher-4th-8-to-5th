🔁 Panda Keeps Going
Last level your code learned to decide. Now it learns to keep going until a job is done — even when you don't know how many steps that takes.
🧠 Start here — the new idea
There's a new command: gems(). It doesn't move the panda — it hands you a number: how many 💎 gems the panda has collected so far. 
say(gems())   →  0     (none yet)
say(gems())   →  3     (after grabbing 3)
Once you have a number, you can compare it. And a comparison gives back true or false — the very same true/false you used with blocked() last level. 
gems() < 5    →  true    (fewer than 5 so far)
gems() < 5    →  false   (5 or more — job done!)

right()left()up()down()blocked()gems()say(...)
