⏱️ Make Them Pop
Here's the new magic: setInterval runs code again and again, all by itself. Yours picks a RANDOM hole and pops a target every so often. Hit START POPPING and just watch!
setInterval(function() { let spot = random(0, 8); // pick a random hole popTarget(spot); // ...and pop it up! }, 800); // every 800 milliseconds, on its own
setInterval is a timer: give it code and a time, and it runs that code over and over forever — no tapping needed. Combined with random, your targets pop in surprise spots. This is the heartbeat of your game!
Build Step 3 of 4
👆 Tap to Score
Now make it a game: when you tap a popped target, your score goes up (an EVENT + an if-statement). Watch out — sometimes a 💣 bomb pops. Don't tap that! Score 8 to continue.
⭐ Score: 0 / 8tap the targets!
hole.onclick = function() { if (hole.hasTarget) { score = score + 1; } if (hole.hasBomb) { score = score - 2; } };
A tap is an event; the if-statements are the rules that decide what the tap does. Target → points. Bomb → ouch. Timers make things happen; events + ifs let YOU respond. That's a game!

Build Step 4 of 4
⏳ Add the Countdown
A reaction game needs pressure — a clock ticking down! Another timer subtracts 1 second each second, and when it hits 0, the game ends. You pick how long the game lasts.
setInterval(function() { timeLeft = timeLeft - 1; // tick... every second if (timeLeft === 0) { endGame(); } // time's up! }, 1000); // 1000 ms = 1 second

20s seconds
One setInterval pops targets fast; another ticks the clock down once per second. Games often run several timers at once — one for the action, one for the countdown. You just wired up both.
