🟰 Phase 2 — Equivalent Fractions (8 min)

Different fractions can name the exact same amount. Those are equivalent fractions.

📋 The Same Amount, Different Names

Look — all three bars are the same length, and the shaded part is exactly the same size. So 1/2 = 2/4 = 3/6:

1/2 ×2/2 = 2/4 1/2 ×3/3 = 3/6
To build an equivalent fraction, multiply the top and bottom by the same number. 1/2 × 2/2 = 2/4. 1/2 × 3/3 = 3/6. To go the other way and simplify, divide top and bottom by the same number: 2/4 ÷ 2/2 = 1/2.

⚖️ Phase 3 — Compare & Add Fractions (10 min)

When the bottom numbers match, comparing and adding gets easy.

📋 Same Bottom Number = Easy

Comparing: when the bottoms are the same, more shaded pieces means a bigger fraction. Here 3/5 > 2/5:

Adding: add the top numbers and keep the bottom the same. 1/5 + 2/5 = 3/5:

Add or subtract the tops, keep the bottom. 1/5 + 2/5 = 3/5  ·  5/6 − 2/6 = 3/6. The bottom number (the denominator) tells you the size of each piece, so it stays the same. If the answer can be simplified, do it: 3/6 = 1/2.
