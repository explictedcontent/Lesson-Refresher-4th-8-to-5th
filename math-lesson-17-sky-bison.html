📖 Phase 2 — Reading a Coordinate Grid (8 min)

Learn how points work, then read points off the grid.

📋 A Point is Written as (x, y)

A coordinate grid has two lines called axes. The x-axis goes ACROSS (left–right). The y-axis goes UP and down. Where they meet is the origin — the point (0, 0).

Every point is written as (x, y). Read it as "across first, then up" — starting from the origin, count how far across (x), then how far up (y).

Point A is (2, 3): across 2, up 3. Point B is (5, 1). Point C is (6, 6).
The first number is ACROSS (the x-axis). The second number is UP (the y-axis). Order matters: (2, 3) is NOT the same spot as (3, 2)!

📋 How to PLOT (x, y)

To plot a point like (4, 2):

Step 1
Start at the origin (0, 0)
Step 2
Go ACROSS 4 (the x)
Step 3
Go UP 2 (the y)
Always go across first, then up — same order as the numbers in (x, y). Mark the point where you land.
