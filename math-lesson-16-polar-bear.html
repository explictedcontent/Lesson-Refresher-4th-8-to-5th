🔢 Phase 2 — Number Patterns (8 min)

Learn how to find the rule of a pattern, then use it to keep it going.

📋 Every Pattern Follows a RULE

A number pattern changes by the same rule every step — like +2, ×3, or −5. To find the rule, look at how you get from one number to the next. Then use that rule to continue.

Adding makes a pattern grow slowly and evenly. Doubling (×2) makes it grow fast — each number is twice the one before. Subtracting makes it shrink. Always test your rule on TWO steps to be sure it fits the whole pattern.

📊 Phase 3 — Function Tables (10 min)

A rule turns every INPUT into an OUTPUT. Learn to read the table, then type the answers.

📋 Input → Rule → Output

A function table has two columns. You put a number IN, the rule does its job, and a number comes OUT. Here the rule is ×3:

InputOutput
1×3 →3
2×3 →6
4×3 →12
The Rule
Output = Input × 3
To find a missing output, do the rule to the input. To find the rule, ask "what did I do to the input to get the output?" — try it on every row to make sure it works. Type rules like ×3 or −3 (you can also write "multiply by 3" or "subtract 3").
