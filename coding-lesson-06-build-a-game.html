Build Step 3 of 4
🎮 Add the Controls
A game you can't control isn't a game! A FUNCTION (Level 2!) moves your catcher. Try the buttons below — OR drag your finger on the game. Move left AND right to continue.

👆 Tap the arrows, or drag on the game. On a keyboard, the ← → arrow keys work too!

function moveCatcher(direction) { catcher.x = catcher.x + direction * 20; }
That function changes your catcher's x property — moving it. Buttons, touch, and keys all call the SAME function. That's why one function can power every control at once.

Build Step 4 of 4
🏆 Set the Rules
Rules turn moving pictures into a GAME. IF you catch a good item → score up. IF you catch a bad item → lose a life. You choose the score needed to WIN!
if (caught === game.good) { game.score = game.score + 1; // nice catch! } if (caught === game.bad) { game.lives = game.lives - 1; // ouch! }
You start with 3 lives ❤️. How many points to WIN?

IF-statements are the RULES of every game: if you touch the coin, score up; if you hit the spike, game over. You just wrote the rules of YOUR game — and picked how hard it is to win.
