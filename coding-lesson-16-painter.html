🧠 Start here — how painting works
The panda stands on a grid. paint() colors the square it's standing on, and right() moves it one square over. 
paint("red")   ← color THIS square red
right()        ← move one square right
Notice the word inside the parentheses: "red". That's an input — extra information you hand to a command so it knows what to do. Words go in quotes.

Your goal each mission: make YOUR PICTURE (left) match the GOAL (right). Press RUN to see it happen.
