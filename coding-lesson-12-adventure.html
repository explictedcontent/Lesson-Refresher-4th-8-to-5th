LEVEL 12: CHOOSE YOUR ADVENTURE

What if the reader picks what happens next? You'll build a branching story — where every choice leads down a different path to a different ending. This is how video-game stories work!

Build Step 1 of 4
🎬 What Is a Scene?
A scene is an OBJECT with some text and a list of CHOICES. Read the scene below and tap a choice to move to the next one!
let scene = { text: "You reach a fork in the path.", choices: [ "Go left", "Go right" ] };
A scene is just an object: some text plus a list of choices. Tapping a choice moves you to another scene. Objects (Level 5) + lists (Level 3), teaming up to tell a story!
Build Step 2 of 4
🍴 Choices Make Branches
Each choice points to a DIFFERENT next scene — that's branching, just like an if/else! Explore a couple of steps and watch the story split.
if (choice === "cave") { goTo(caveScene); } else { goTo(riverScene); } // each choice = a branch
Every choice is a branch — like an if/else that sends the story a different way. Two choices at each scene quickly grow into MANY possible paths. That's the magic of branching stories.
Build Step 3 of 4
🔚 Reaching an Ending
Some scenes have NO choices — they're endings, where a path stops. Follow any path all the way to an ending!
if (scene.choices.length === 0) { showEnding(); // no choices = THE END }
An ending is a scene with no choices — the path stops there. A good adventure has several different endings, so every set of choices tells a different story. You just reached one!

You reached an ending!
