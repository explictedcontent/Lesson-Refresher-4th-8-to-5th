4–9 min Teach: How Place Value Works

Every digit has two things: the digit itself, and the place it sits in. The place tells you what it's worth. Each place to the left is 10× bigger than the one to its right.

Millions | Hund-Thous | Ten-Thous | Thousands | Hundreds | Tens | Ones
1,000,000   100,000     10,000      1,000        100      10      1

We split big numbers into periods of three, separated by commas: 3,205,070 reads "three million, two hundred five thousand, seventy." Read to a comma, say "million," read to the next comma, say "thousand," then the rest.

28–30 min 👑 Boss: Mystery Numbers

56. Crack the code. A 5-digit number where the ten-thousands digit is 8, thousands is 0, hundreds is 4, tens is 0, ones is 7.
57. Tougher code. A 6-digit number: hundred-thousands is 3, ten-thousands is 0, thousands is 9, and hundreds, tens, ones are 0, 0, 4.

Then say it out loud: "Tell me one thing you learned about place value today."

✨ Stretch & Number Riddles (extra XP)

S1. What is the largest 6-digit number you can make?
S2. Between 100 and 200: tens digit is 5, ones digit is 3 more than the tens. What number?
S3. A 3-digit number: hundreds digit is 4, tens digit is double the hundreds, ones digit is 1 less than the tens. What number?
S4. A 2-digit number: tens digit is 7, ones digit is 2 less than the tens. What number?
S5. A 4-digit number: thousands digit is 5, hundreds is 0, tens digit equals the thousands digit, ones is 0. What number?
S6. Use the digits 7, 0, 5, 3, 9, 1 exactly once each to make the largest 6-digit number.
S7. Use the digits 4, 0, 7, 1, 9 exactly once each to make the smallest 5-digit number. (can't start with 0!)
S8. Write the number for "three million, forty thousand, two." (7 digits!)
